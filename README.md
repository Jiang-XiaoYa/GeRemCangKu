# 桌面文件自动整理工具 (Desktop File Organizer)
 **一个极简、零依赖、纯 Python 标准库编写的桌面文件自动化分类脚本。**
## 📖 项目简介
本项目旨在解决日常办公中桌面文件堆积杂乱的痛点。基于 Python 官方标准库（`os`, `shutil` 等）开发，**无需安装任何第三方包**，开箱即用。支持根据文件后缀（如文档、图片、压缩包、快捷方式等）自动创建分类文件夹，并将文件移动至对应目录。
## ✨ 核心特性
*   **🚀 纯血零依赖**：完全基于 Python 3 标准库，无需 `pip install` 任何包。
*   **🛡️ 防御性整理逻辑**：内置安全排除机制，自动忽略工程代码文件夹及系统隐藏文件，避免破坏开发环境。由于安全机制并不完善使用前请先阅读代码保证安全性。
*   **🔁 幂等性安全**：使用 `os.makedirs(exist_ok=True)` 机制，重复运行不会覆盖或报错。
*   **⚖️ 开源协议**：采用 **GPL-3.0** 协议，保护代码不被恶意商业封装与倒卖。
